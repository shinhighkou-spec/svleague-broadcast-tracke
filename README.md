# SV.LEAGUE 放送予定 自動収集

SV.LEAGUE 2026-27シーズンのテレビ放送予定をPlaywrightで取得し、
検証後にGitHub Pagesへ公開するプロジェクトです。

## 表示

- 放送局
- 放送日
- ホームチーム
- アウェイチーム

放送時間は内部検証に使用しますが、公開表には表示しません。

## 自動更新

GitHub Actionsで毎日、日本時間06:00ごろに実行します。
公式取得や検証に失敗した場合は、直前の正常データを保持します。

## GitHub Pages

リポジトリの **Settings → Pages → Source = GitHub Actions** にしてください。

## ローカル実行

```bash
pip install -r requirements.txt
playwright install chromium
pytest -q
python scraper.py
```


## 運用ルール（必ず守る）

### 一覧の対象
- 公開ページは**テレビ放送予定専用**。地上波・BS・CSなどのテレビ放送のみ掲載する。
- オンデマンド専用配信（例：J SPORTSオンデマンド）はテレビ放送一覧に掲載しない。テレビ放送と同時に配信される場合も、一覧の対象はテレビ放送局だけとする。
- SV.LEAGUE公式サイト・公式SNSが放送予定を告知した場合、放送局側の番組表への掲載を待たずに登録する。公式発表は一次情報として扱う。
- 公式SNSの画像投稿も対象とする。本文テキストだけで判断せず、画像内の放送局・日付・時刻・対戦カードを確認する。読めない項目は推測で補完しない。
- 地方局を対象から漏らさない。放送局名は `VALID_STATIONS` と回帰テストに明示する。

### 変更前後の必須確認
1. 既存の会話で指定された放送情報と、公式発表の既知情報を確認する。
2. 新情報をテレビ放送／オンデマンド等に分類してから登録する。
3. 重複・誤記・必須情報の欠落を検査する。根拠なく既存の公式発表情報を削除しない。
4. `pytest -q` を通過させる。対象媒体の混入、既知情報の欠落、JSONとHTMLの不一致は失敗にする。
5. 公開データ更新後、GitHub Actionsの結果と公開ページの実表示を別々に確認する。
6. 1件でも放送予定を追加・修正して公開反映した場合は、その事実を明示して通知する。未確認の状態を「完了」と報告しない。
7. 収集処理の失敗、画像を確認できなかったこと、公開反映の失敗は隠さず、未完了として報告する。

### 完了の定義
ファイルへのコミットだけでは完了ではない。テスト成功、Actions成功、公開ページでの実表示を確認した時点で公開反映完了とする。確認できない項目は「未確認」と明記する。
